# Animation

A compact study of Flutter animation fundamentals.

## Highlights

- Implicit animations — the framework animates a property change for you.
- Explicit animations — full control via `AnimationController` and `Tween`.
- Easing curves demonstrated so transitions feel intentional.

## Tech Stack

| Concern | Choice |
|---|---|
| UI | Flutter, Material |
| Animation | `AnimationController`, `Tween`, `Curves` |

## Project Structure

```
lib/
- `main.dart`
```

## Getting Started

### Prerequisites

- Flutter `>= 3.16` (Dart `>= 3.2`)

### Run

```bash
git clone https://github.com/developer-rahim/Animation.git
cd Animation
flutter pub get
flutter run
```

### Test

```bash
flutter test
flutter analyze
```
